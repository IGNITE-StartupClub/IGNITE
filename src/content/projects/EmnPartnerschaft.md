# IGNITE x European Mentorship Network: Mentoring über den Campus hinaus

Wir haben einen neuen Partner: Das European Mentorship Network (EMN) verbindet Gründer:innen in der Frühphase mit Mentor:innen aus ganz Europa. Für Gründer:innen ist das Mentoring kostenlos, und die IGNITE-Community bekommt auf der Plattform ihren eigenen Bereich.

#### Was ist das European Mentorship Network?

Du hast eine Idee oder weißt nicht genau, was dein nächster Schritt ist? Auf dem EMN findest du Mentor:innen nach Thema, Phase und Verfügbarkeit und kannst direkt eine Session anfragen.

Die Mentor:innen kommen über Partnernetzwerke aus ganz Europa. So bekommst du Feedback über deinen eigenen Campus und dein Land hinaus.

#### Deine eigene IGNITE-Community auf der Plattform

Als IGNITE-Mitglied bekommst du auf dem EMN einen IGNITE-Badge. Damit kannst du gezielt nach Mentor:innen aus unserer Community filtern, und IGNITE-Mentor:innen finden dich. So bleibt der Austausch nicht nur international, sondern auch nah an unserem Netzwerk in Lüneburg.

#### So bist du dabei

Den Zugangscode für die IGNITE-Community bekommst du als Mitglied direkt von uns.

1. Registriere dich mit dem Code auf [europeanmentorshipnetwork.com](https://www.europeanmentorshipnetwork.com).
2. Gib denselben Code unter **Profil → Communities** ein, um deinen IGNITE-Badge zu erhalten.

Du willst lieber selbst mentoren? Dann registriere dich mit demselben Code als Mentor:in.

#### Danke!

Ein großes Dankeschön an das Team des European Mentorship Network für die unkomplizierte Zusammenarbeit. Wir freuen uns darauf, was aus den ersten Sessions entsteht! 🚀
